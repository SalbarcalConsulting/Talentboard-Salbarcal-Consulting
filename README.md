# TalentBoard – Recruiting Suite

Professionelles Bewerbermanagement für Recruiting-Agenturen.

## Features
- Multi-Mandanten Login (Admin + Kunden getrennt)
- Kanban-Pipeline & Bewerberliste
- E-Mail-Funktion mit KI-Entwurf
- KI-Assistent (powered by Claude)
- Admin-Panel zur Kundenverwaltung

## Lokale Entwicklung

```bash
npm install
npm run dev
```

## Deployment auf Vercel
1. Repository auf GitHub hochladen
2. Auf [vercel.com](https://vercel.com) einloggen
3. „Import from GitHub" → dieses Repository auswählen
4. Deploy klicken – fertig!
